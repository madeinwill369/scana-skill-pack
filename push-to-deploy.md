# Push to Deploy Pipeline

**Category:** engineering

**Description:** None

## Instructions

Ideal pipeline for Master Will's projects: 1) Push to GitHub main. 2) Anigmae detects push via webhook. 3) folk pulls latest code. 4) Runs tests if they exist. 5) Builds Docker image. 6) Deploys to Fly.io. 7) Updates city status. 8) Notifies via Telegram. Full autonomous CI/CD.

# On New Feature Access

**Category:** continuity

**Description:** None

## Instructions

When Master Will accesses or connects a new service/feature (e.g. new API, new app, new integration), immediately: 1) Store credentials in identity DB. 2) Create or update a memory entry describing the service. 3) Register the capability in folk-prime's awareness. 4) Log event='feature_unlocked' to world log.

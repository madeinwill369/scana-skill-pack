# Replit Migration Protocol

**Category:** engineering

**Description:** None

## Instructions

To migrate from Replit: 1) User opens Replit project. 2) Opens Git panel. 3) Stages all files. 4) Commits with message. 5) Pushes to GitHub. 6) folk pulls from GitHub and inspects. 7) folk creates fly.toml and Dockerfile. 8) Deploy to Fly.io under SCANA org. 9) Register as new city in Anigmae.
